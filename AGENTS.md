Guidelines for working in this repository:
- The extension has two runtime contexts (Node.js extension host and browser
  webview) — know which one your code runs in before using fs, window, or
  process.env.
- API URL is resolved at runtime by resolveApiUrl() in src/utils/resolveApiUrl.ts
  and passed to the webview via window.__NV_API_URL__ in the HTML generated by
  extension.ts. Do not import resolveApiUrl.ts from webview code — it uses
  Node.js APIs (fs, os) that don't exist in the browser.
- Run make test before declaring anything done — it catches webpack,
  TypeScript, ESLint, and runtime issues in one shot.
- Always check git status before committing — the user may have committed or
  rebased independently.
- Git history is a first-class artifact — put changes in the correct commit,
  write accurate messages, and never leave dead code behind.
- The supported languages list is hardcoded in ApiDiscovery.tsx — check
  nightvision swagger extract --help for the CLI's actual --lang options.
- npm ci is used in CI, so always commit package-lock.json after dependency changes.
- The user handles all pushes and PR creation — never push without explicit
  permission.
